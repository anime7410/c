# **COMPUTER NETWORKS – PRACTICAL 5 CHEAT SHEET**



Quick execution guide

Cisco Packet Tracer



**Aim:** Configure routers using RIP routing protocol and establish communication between different networks.

## **1. Create Network Topology**

**Add devices:**

- 2 Routers (Router2, Router3)
- 2 Switches
- 1 Laptop (Laptop0)
- 1 PC (PC0)

**Connect devices:**

| Connection        | Cable                   |
| ----------------- | ----------------------- |
| Laptop → Switch   | Copper Straight-Through |
| Switch → Router2  | Copper Straight-Through |
| Router2 → Router3 | Serial DCE/DTE          |
| Router3 → Switch  | Copper Straight-Through |
| Switch → PC       | Copper Straight-Through |

## **2. Configure IP Addresses**

**End devices:** Desktop → IP Configuration → Static.

| Device  | IP Address    | Subnet Mask     | Gateway       |
| ------- | ------------- | --------------- | ------------- |
| Laptop0 | `192.168.1.2` | `255.255.255.0` | `192.168.1.1` |
| PC0     | `192.168.2.2` | `255.255.255.0` | `192.168.2.1` |

## **3. Configure Router2**

Router2 → Config → FastEthernet0/0:

| Field       | Value           |
| ----------- | --------------- |
| IP Address  | `192.168.1.1`   |
| Subnet Mask | `255.255.255.0` |
| Port Status | ON              |

Router2 → Serial2/0:

| Field       | Value            |
| ----------- | ---------------- |
| IP Address  | `10.10.0.2`      |
| Subnet Mask | `255.0.0.0`      |
| Port Status | ON               |
| Clock Rate  | `72000` (if DCE) |

## **4. Configure Router3**

Router3 → Config → FastEthernet0/0:

| Field       | Value           |
| ----------- | --------------- |
| IP Address  | `192.168.2.1`   |
| Subnet Mask | `255.255.255.0` |
| Port Status | ON              |

Router3 → Serial2/0:

| Field       | Value       |
| ----------- | ----------- |
| IP Address  | `10.10.0.3` |
| Subnet Mask | `255.0.0.0` |
| Port Status | ON          |

Set clock rate only on the DCE end.

## **5. Configure RIP Routing**

Most important step

**Router2 → Config → RIP**

Add these network addresses one by one:

```
10.0.0.0
192.168.1.0
```

**Router3 → Config → RIP**

Add:

```
10.0.0.0
192.168.2.0
```

Click Add after entering each network.

## **6. Save Router Configurations**

Router → Config → Settings → NVRAM → Save.

Repeat for both routers.

## **7. Verify Connectivity**

Laptop0 → Desktop → Command Prompt:

```
ping 192.168.2.2
```

From PC0:

```
ping 192.168.1.2
```



Success

&#x20;Successful replies with 0% packet loss.



If the first ping times out, repeat after allowing time for ARP resolution and RIP route learning.

## **8. Important RIP Theory**

| Term                      | Meaning                      |
| ------------------------- | ---------------------------- |
| RIP                       | Routing Information Protocol |
| Type                      | Distance Vector              |
| Metric                    | Hop Count                    |
| Maximum hop count         | 15                           |
| Hop count 16              | Destination unreachable      |
| Update interval           | 30 seconds                   |
| UDP port                  | 520                          |
| RIPv1                     | Classful routing             |
| RIPv2                     | Classless routing            |
| Multicast address (RIPv2) | 224.0.0.9                    |

**Static vs Dynamic Routing**

- Static: Routes configured manually.
- Dynamic: Routes learned automatically using routing protocols.

## **9. RIP Loop Prevention**

| Technique       | Function                                                                        |
| --------------- | ------------------------------------------------------------------------------- |
| Split Horizon   | Does not advertise a route back through the interface from which it was learned |
| Hold-down Timer | Temporarily prevents acceptance of potentially incorrect route updates          |
| Poison Reverse  | Advertises a learned route back with infinite metric (16)                       |

## **10. Viva – Quick Revision**

1. **What is RIP?** Dynamic routing protocol used to exchange routing information.
2. **What is hop count?** Number of routers traversed to reach a destination.
3. **Maximum hop count?** 15.
4. **What does 16 indicate?** Destination unreachable.
5. **Difference between RIPv1 and RIPv2?** RIPv1 is classful; RIPv2 is classless and supports VLSM.
6. **Why is RIP unsuitable for large networks?** Limited hop count, slow convergence and periodic updates.
7. **What is Split Horizon?** Prevents advertising a route back through the interface from which it was learned.
8. **What is dynamic routing?** Automatic exchange and updating of routing information.
9. **What is a routing table?** Table containing routes used to forward packets.
10. **Why use serial connection?** To establish a WAN link between routers.
