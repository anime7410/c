# **COMPUTER NETWORKS – PRACTICAL 6 CHEAT SHEET**



Quick execution guide

TeamViewer



**Aim:** Establish remote communication and access between two computers using TeamViewer.

Important: Your newly uploaded PDF is Experiment 6 (TELNET/remote access using TeamViewer), not Experiment 8. The following cheat sheet follows the uploaded Experiment 6 writeup.

## **1. Requirements**

- Two computers (Host PC and Remote PC).
- Internet connection.
- TeamViewer installed on both computers.

Download: [TeamViewer official website](https://www.teamviewer.com/?utm_source=chatgpt.com).

## **2. Install TeamViewer**

On both computers:

1. Open TeamViewer installer.
2. Select **Basic Installation**.
3. Select **Personal / Non-commercial use**.
4. Accept the license agreement.
5. Click Install / Next.
6. Open TeamViewer.

## **3. Establish Remote Connection**

Most important step

**On Host PC (computer to be controlled):**

1. Open TeamViewer.
2. Note down **Your ID**.
3. Note down **Password**.

**On Remote PC (computer controlling the host):**

1. Open TeamViewer.
2. Enter Host PC's ID in **Partner ID**.
3. Select **Remote Control**.
4. Click Connect.
5. Enter Host PC's password.
6. Click Log On.

## **4. Perform Remote Operations**

After connection, perform these operations:

- Move mouse pointer on remote desktop.
- Open and close applications.
- Move desktop icons.
- Access folders and files.
- Make permitted system configuration changes.

## **5. File Transfer Between Computers**

Important practical step

1. Establish remote connection.
2. On the remote-control window, click **Files & Extras**.
3. Select **File Transfer**.
4. File Transfer window opens.

## **8. Viva – Quick Revision**

1. **What is Telnet?** An application-layer client-server protocol used for remote login and communication with another computer.
2. **What is the default Telnet port?** TCP port 23.
3. **What is TeamViewer?** Software used for remote computer access, control, meetings and file transfer.
4. **What is Partner ID?** Unique ID used to identify the remote computer.
5. **What is Remote Control?** A feature that allows one computer to operate another computer remotely.
6. **How do you transfer files in TeamViewer?** Files & Extras → File Transfer → Browse → Drag and Drop.
7. **What is the use of Chat?** Communication between connected users.
8. **What is session recording?** Recording a remote session in `.tvs` format.
9. **Why is Telnet insecure?** It transmits communication, including credentials, without encryption.
10. **Difference between Telnet and SSH?**

| Telnet       | SSH                 |
| ------------ | ------------------- |
| TCP port 23  | TCP port 22         |
| Unencrypted  | Encrypted           |
| Less secure  | More secure         |
| Remote login | Secure remote login |

**Important distinction:** TeamViewer is not the Telnet protocol. Your writeup uses TeamViewer to demonstrate remote access and communication. TeamViewer connections are encrypted, unlike standard Telnet.
