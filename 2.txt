## **1. Star Topology – Execution Steps**

**Step 1. Open Cisco Packet Tracer** → Select Logical Workspace.

**Step 2. Add devices**

- End Devices → Add 5 PCs (PC0–PC4).
- Network Devices → Switches → Select 2950-24.

**Step 3. Connect devices**

- Select Connections (Lightning icon).
- Select Copper Straight-Through.
- Connect each PC's `FastEthernet0` to a separate switch port.

| PC  | Switch port |
| --- | ----------- |
| PC0 | Fa0/1       |
| PC1 | Fa0/2       |
| PC2 | Fa0/3       |
| PC3 | Fa0/4       |
| PC4 | Fa0/5       |

**Step 4. Assign static IP addresses**

For each PC: Click PC → Desktop → IP Configuration → Static.

| PC  | IP Address  | Subnet Mask   |
| --- | ----------- | ------------- |
| PC0 | 192.168.1.1 | 255.255.255.0 |
| PC1 | 192.168.1.2 | 255.255.255.0 |
| PC2 | 192.168.1.3 | 255.255.255.0 |
| PC3 | 192.168.1.4 | 255.255.255.0 |
| PC4 | 192.168.1.5 | 255.255.255.0 |

Default Gateway and DNS: Leave blank.

**Step 5. Test connectivity**

PC0 → Desktop → Command Prompt:

```
ping 192.168.1.2
```



Success

`Reply from 192.168.1.2` and 0% packet loss.



**Step 6. Save the project** using File → Save As.

## **2. Other Topologies – Quick Implementation**

| Topology | Implementation                                                                               |
| -------- | -------------------------------------------------------------------------------------------- |
| Star     | All PCs connect to one central switch.                                                       |
| Bus      | PCs connect to a shared medium; a hub-based simulation approximates shared-medium behaviour. |
| Ring     | Connect switches in a circular arrangement.                                                  |
| Mesh     | Connect every device directly to every other device (full mesh).                             |
| Tree     | Connect multiple switches hierarchically.                                                    |
| Hybrid   | Combine two or more topologies, e.g. two star networks connected together.                   |

**Full mesh formula:**

\\[ \text{Connections}=\frac{n(n-1)}{2} \\]

For 4 devices = 6 connections.

**Cable selection:**

- PC to Switch → Copper Straight-Through.
- Switch to Switch → Copper Cross-Over traditionally; automatic connection may also work.

For a ring of switches, STP may block one redundant link to prevent loops.

## **3. Important Theory – Quick Revision**

| Term                | Meaning                                                  |

| LAN                 | Local Area Network                                       |

### **Straight-through vs Crossover**

- Straight-through: Same wiring standard at both ends (T568A–T568A or T568B–T568B).
- Crossover: Different standards at both ends (T568A–T568B).

## **4. Viva – Must Remember**

1. **Which topology is commonly preferred for LAN?** Star, because it is easy to manage, expand and troubleshoot.
2. **What happens if the central switch fails?** The entire star network stops working.
3. **Why use a switch?** To connect devices within a LAN and forward frames using MAC addresses.
4. **Why assign different IP addresses?** To uniquely identify each network interface within the subnet.
5. **Why use the same subnet mask?** To place the PCs in the same IP subnet.
6. **Why use Ping?** To verify connectivity between computers.
7. **What is Hybrid Topology?** Combination of two or more topologies.
8. **What is Packet Tracer?** Cisco network simulation software.
